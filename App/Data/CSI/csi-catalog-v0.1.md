# CSI v0.1 — Classificação Semiológica Internacional

Camada semântica universal para padronização de documentos médicos heterogêneos.

Objetivos:
- desacoplar significado clínico de layout documental;
- permitir interoperabilidade entre documentos;
- servir como núcleo universal de tradução semiológica;
- estruturar preenchimento automático semântico.

Status:
v0.1 — núcleo inicial.
