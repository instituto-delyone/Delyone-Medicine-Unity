# 06 — Matriz LGPD

| Tema | Estado | Evidência / documento |
|---|---|---|
| Mapeamento de tratamentos | PENDENTE | RoPA/mapa de dados |
| Finalidades | A VALIDAR | inventário de processos |
| Bases legais | A VALIDAR | matriz jurídica por fluxo |
| Papéis controlador/operador | A VALIDAR | contratos + análise de fluxo |
| Dados biométricos | A VALIDAR | DPIA/análise de risco, se aplicável |

| Eliminação/anonimização | PENDENTE | procedimento técnico |

| Compartilhamentos | PENDENTE | inventário + contratos |
| Suboperadores | PENDENTE | cadastro/contratos |
| Segurança | EM IMPLANTAÇÃO | PSI + matriz de controles |
| Incidentes | EM IMPLANTAÇÃO | plano de resposta |
| Registro de evidências | A VALIDAR | trilha de auditoria |
| Transparência | PENDENTE | política pública |

## Observação

O fato de um tratamento estar listado nesta matriz não significa que ele já seja realizado pelo Instituto. O inventário deve refletir o fluxo real em produção.
