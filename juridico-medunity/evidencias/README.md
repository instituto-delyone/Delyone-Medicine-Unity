# Evidências — Jurídico MedUnity

Pasta reservada para documentos de suporte ao dossiê jurídico.

Exemplos: registros oficiais, contratos, documentos societários, comprovantes de autoria, documentos do INPI, pareceres, políticas aprovadas e evidências técnicas relevantes.

Não armazenar senhas, tokens, chaves privadas, JWTs, secrets ou credenciais.

Antes de inserir documentos sensíveis, verificar se o repositório e o arquivo têm o nível de acesso adequado.
