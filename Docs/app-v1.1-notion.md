# Delyone Med Unity — App v1.1

## Natureza

Primeira versão organizada em arquivos separados:

- `App/index.html`
- `App/Css/style.css`
- `App/Js/app.js`
- `Data/canonical-fields.json`
- `Templates/*.html`

## Objetivo

Separar estrutura, estilo, lógica, dados e modelos documentais para tornar o projeto mais profissional, expansível e controlável no GitHub.

## Funcionalidades

- Mother Form preenchível
- Campos canônicos
- Cálculo automático de idade
- Data e hora automáticas
- Geração de preview
- Preview editável
- Copiar
- Baixar HTML
- Imprimir
- Limpar ficha
